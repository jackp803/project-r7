# Product research native provenance v0.2

Application owner adapter under the approved master v0.2 native product scope.
Legacy numerical, registry, approval, E7 runtime and financial contracts remain
unchanged. This profile concerns actual research assessment publication only.

Source research in LOCAL_RESEARCH still requires recorded LOCAL execution,
full executable SHA, CLEAN source provenance and the existing exact current
implementation/namespace, owner journal, frozen finalist and sealed result checks.
DIRTY, missing revision and an unavailable source worktree stay denied.

A frozen product has no installed Git checkout. Its actual provenance therefore
retains worktree=UNAVAILABLE. The frozen assessment consumer re-runs the existing
native distribution verifier against its own current executable installation and
compares the complete measured producer provenance with the immutable run record.
The verifier checks the exact native inventory, binary/resources, source and SQL,
OS/architecture/interpreter, source executable revision and build hash. A source
process, caller metadata, wrong build, tampered installation or changed executable
cannot substitute for this actual frozen consumer. No caller verification flag,
alternative package path or namespace override is accepted.

Every other actual E2/E3/E5/E6 assessment gate remains mandatory. Synthetic
mechanical inputs remain identified as synthetic; the public native research
entrypoint uses LOCAL_RESEARCH, without making that namespace real data, real
forward observation or financial permission. No previously executed FIXTURE
evidence, approval, journal or result may be relabelled to another namespace.

The native inventory has financial_authority=NONE. This profile does not assert
signed/qualified release status and cannot authorize PAPER/LIVE, restore approval,
reset reconciliation, expose capital or replace the accepted E7 consumer proof.
Native source/asset integrity, executed research assessment, full qualification,
human consent and provider commissioning remain distinct evidence subjects.
